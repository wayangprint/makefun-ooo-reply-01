## The entry

> I'm out of office — my inbox is now self-governing and has already voted to ignore you.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the single entry line, deterministically, to `/output/entry.txt` (UTF-8, one line, no trailing newline). The same line is also committed as `entry.txt` at the repository root.
